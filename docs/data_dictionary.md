# Data Dictionary

All records are synthetic. Identifier formats are deterministic and generated by the data-generation script.

## Tables

| Table | Purpose | Primary identifier / key |
|---|---|---|
| `employee` | Employees, roles, departments, joining dates, and status | `employee_id` |
| `role` | Job roles and their departments | `role_id` |
| `skill` | Skill catalogue, categories, and status | `skill_id` |
| `role_skill_target` | Required proficiency for each role-skill pair | `role_id`, `skill_id` |
| `employee_skill` | Assessed proficiency for employee-skill pairs | `employee_id`, `skill_id` |
| `course` | Learning catalogue, duration, cost, capacity, availability, and status | `course_id` |
| `course_skill` | Skills taught by courses and expected proficiency gains | `course_id`, `skill_id` |
| `prerequisite` | Required course-to-course prerequisites | `course_id`, `prerequisite_course_id` |
| `enrollment` | Employee course enrolment and status | `enrollment_id` |
| `completion` | Completion date and outcome for an enrollment | `completion_id` |
| `budget` | Approved budget for each department and fiscal year | `budget_id` |

## Important Columns

### Employee

- `employee_id`: Employee identifier, such as `EMP-000001`.
- `role_id`: Assigned role identifier.
- `department`: Employee's department.
- `joining_date`: Synthetic joining date.
- `status`: Employee status.

### Role Skill Target

- `target_proficiency`: Required proficiency level for a role-skill pair.
- `effective_from`: Date the target becomes effective.
- `effective_to`: Optional end date; blank means no end date is specified.

### Employee Skill

- `proficiency`: Assessed employee proficiency.
- `assessed_on`: Date of the skill assessment.
- `assessment_status`: Status of the assessment.
- `gap`: Positive difference between the target proficiency and current proficiency, floored at zero.

### Course

- `duration_hours`: Expected learning duration in hours.
- `cost`: Course cost in INR.
- `capacity`: Maximum number of course seats.
- `available_from`, `available_to`: Availability window.
- `status`: Course status.

### Course Skill

- `expected_proficiency_gain`: Expected proficiency improvement associated with the course.

### Enrollment

- `enrollment_date`: Enrollment date.
- `status`: Enrollment lifecycle status, such as enrolled, in progress, completed, or cancelled.

### Completion

- `completion_date`: Recorded completion date.
- `result`: Completion outcome, such as passed or failed.

### Budget

- `fiscal_year`: Budget year.
- `allocated_amount`: Approved department budget.
- `currency`: Currency code, currently INR.

## Relationship Summary

- Each employee references a role.
- Roles and skills are linked through `role_skill_target`.
- Employee assessments link employees to skills through `employee_skill`.
- Courses and skills are linked through `course_skill`.
- Courses can reference prerequisite courses through `prerequisite`.
- Enrollments reference employees and courses.
- Completion events reference enrollments.
- Department budgets constrain learning allocations.
